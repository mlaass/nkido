Edge Cases\n   293\t\n   294\t1. **Benchmark noise / thermal drift.** Long runs heat the machine and slow late\n   295\t   iterations. Falls to\n   303\t   the tolerance path; requires the declared `// simd: approx` comment.\n   304\t5. **Approximation passes the null test but changes musical behaviour** \u2014 e.g. a\n   305\t   `tanh` approximation that alters a filter's self-oscillation. Caught by the\n   306\t   winners-only listening pass; if it fails there, the change is rejected even\n   307\t   though every automated gate was green.\n   308\t6. **SIMD is slower.** Expected for C4 (feedback-serial).
