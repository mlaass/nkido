## scripts/autoresearch/ — 15 files touched across 12 commits

### Parallel lanes and machine-wide benchmarking lock

- **feat(autoresearch): parallel lanes with a machine-wide build/bench lock** (`69a720d`)
  `verify.py` wraps the full verify sequence (baseline prep, quick checks, full bench) in an `flock` on `runs/.machine.lock`, preventing any two benchmark runs from overlapping across parallel sweep lanes. Lock wait time is logged per iteration as `lock_wait_s` (counts against the 30-min wall clock, so it is recorded rather than hidden).

- **fix(autoresearch): remote leg on macOS + serial sweep driver** (`aa9bf86`)
  `legs.py`: fixed relative remote dir (script `cd`'s into `src/` before building, so cedar_bench was never found); added `/opt/homebrew/bin` to PATH (non-interactive SSH skips Homebrew) and SSH keepalives (silent cmake build outlived cloudflared idle timeout). Verified on M4 mini. `sweep.sh` introduced as a full model-matrix driver, one run at a time, resumable, with a $30 total OpenRouter cap.

### Resume/pause system

- **feat(autoresearch): pause at iteration boundaries, resume stopped runs** (`9d656b8`)
  `run.py --resume RUN_DIR` rebuilds loop state from `iterations.jsonl` (attempts, dup-check diffs from saved reject patches, current ns, USD spent) and continues in the same worktree + branch, resetting any edits cut off at the boundary. `runs/STOP` file pauses before the next iteration; `sweep.sh` defers new work and resumes an unfinished run instead.

- **test(autoresearch): replay() rebuilds resume state from the log** (`97cb282`)
  `test_harness.py`: added `replay()` test that verifies replaying `iterations.jsonl` correctly reconstructs budget spent, speed-baseline ns, and dup-check state.

### Observability and reporting

- **feat(autoresearch): log propose-phase lock wait, report active time** (`b95c1c0`)
  `run.py` records `lock_wait_propose_s` (the portion of lock wait that falls inside an attempt's wall clock); `report.py` displays wall clock minus that as active time when all iterations of a run have it.

- **fix(autoresearch): retry transient upstream failures in the OpenAI-compat loop** (`5e30516`)
  `backends/openai_compat.py`: 5xx/429 responses and near-empty replies (single token, no tool call) are retried up to twice, matching Claude CLI's own retry behavior. Each retry is logged as a capability gap. `model_resolved` records the upstream name per turn (e.g., `deepseek-v4-pro@baidu`).

### OpenRouter backend refinement

- **feat(autoresearch): OpenRouter throughput routing, $6/run and $50 total cap** (`88b05422`)
  `openrouter.py`: added `provider.sort=throughput` to force fastest upstream (default routed deepseek to Baidu at 20 tok/s, qwen to DeepInfra at 30-40 tok/s causing 4/5 iterations to hit the 30-min wall clock). Per-run budget raised to $6; total sweep cap to $50.

- **revert(autoresearch): drop OpenRouter throughput sort** (`44e28345`)
  `provider.sort=throughput` had no observable effect — deepseek-v4-pro still routed to Baidu (28.9 min, 53 turns); the endpoints list reports no throughput data. Reverted to default routing; slow upstreams are recorded via `model_resolved`.

- **docs(autoresearch): record cheap/free OpenRouter extension models** (`65b0da0`)
  `openrouter.py`: documented four paid extension models (glm-5.3-flash, deepseek-v4-flash-0731, qwen3-coder-next, gpt-6-luna) and four `:free` models added as three extra serial lanes during the sweep.

- **docs(autoresearch): drop laguna-s-2.1:free from extension** (`4cb85ce`)
  Removed `laguna-s-2.1:free` from the model list due to persistent upstream 429s.

### New backend: Codex CLI

- **feat(autoresearch): Codex CLI backend (codex exec on the ChatGPT subscription)** (`75e78d2`)
  `backends/codex.py`: new backend using `codex exec --json --ephemeral --ignore-user-config` in workspace-write sandbox; writable roots are the worktree, `runs/` (check.sh + machine lock) and ccache. Subscription usage has no per-call price (`cost_usd None`). Commands beyond `check.sh` are logged as capability gaps. Smoke run: `gpt-reserve arith`, 1 iteration, check.sh built + benched inside the sandbox, accepted at 1.30×.

- **feat(autoresearch): rollback.py and watch.py sweep helpers** (`267d22d`)
  `rollback.py`: moves a run's contiguous tail of access/quota failures (key or budget 403, credits 402, free-tier 429, Codex usage limit) to `iterations.403.jsonl` and reopens the run so `sweep.sh` redoes those iterations. `watch.py`: polls run logs for real-time monitoring — one line per iteration with access errors flagged, finished runs, lane exit. Both scripted from ad-hoc tools used during the 2026-09-26/27 sweep.
